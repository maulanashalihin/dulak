---
title: Cloudflare Pages
description: Publish the site to Cloudflare Pages.
---

The site is a fully static Astro build — no server adapter needed.
Cloudflare Pages serves the `dist/` output directly.

## Option A: Cloudflare dashboard

1. Create a Pages project connected to the `dulak` GitHub repository.
2. Build configuration:
   - **Root directory**: `site`
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`
3. Deploy. Each push to `main` redeploys automatically.

## Option B: Wrangler CLI

```bash
cd site
npx wrangler pages deploy dist --project-name dulak-site
```

`site/wrangler.toml` already pins the project name and build output dir:

```toml
name = "dulak-site"
pages_build_output_dir = "dist"
compatibility_date = "2026-08-05"
```

## Option C: GitHub Actions (CI)

A workflow (`.github/workflows/deploy-site.yml`) builds the site and deploys
with Wrangler. Add these repository secrets first:

- `CLOUDFLARE_API_TOKEN` — token with `Cloudflare Pages: Edit` permission
- `CLOUDFLARE_ACCOUNT_ID` — your Cloudflare account id

## Custom domain

Set the `site` in `site/astro.config.mjs` to your production URL (currently
a placeholder) so canonical URLs are correct, then add the custom domain in
the Pages dashboard.

## Local preview

```bash
cd site
npm install
npm run dev      # http://localhost:4321
npm run build    # static output → site/dist
```
