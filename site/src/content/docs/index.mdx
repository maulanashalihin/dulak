## Why Dulak?

The name is the philosophy — *bored* in Banjar. Every choice favors the next maintainer, human or AI agent:

- **One obvious way to do things.** Routes in `routes/<feature>.routes.ts`, all SQL in `db.ts`, schema in versioned migrations. No feature folders, no second way to do the same thing.
- **Discoverability as a contract.** Given any URL you can derive the file that owns it.
- **Boring versions, current versions.** Hono 4.x, Bun 1.3. Upgrades are deliberate decisions.
- **AI-agent friendly.** TypeBox schemas, strict TypeScript, documented conventions (`AGENTS.md`), deterministic tests (`bun test --isolate`).
