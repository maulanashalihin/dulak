Read `AGENTS.md` at the repo root first — it codifies the layout and
convention rules (a condensed version is on the
[Conventions](/architecture/conventions/) page).

## Before you start

- Follow the structural rules: routes in `routes/<feature>.routes.ts`,
  all SQL in `db.ts`, env only in `config.ts`, TypeBox for validation.
- Match the repo style: 2-space indent, double quotes, semicolons.

## Verification

```bash
bun run typecheck
bun run lint         # = biome lint src tests scripts create-dulak
bun run test         # = bun test --isolate — NEVER plain bun test
```

- The suite must stay green.
- `--isolate` is required: each test file sets its env in `beforeAll` and
  closes the DB in `afterAll` as if process-isolated.
- `tsc` only covers `src/` and `scripts/` — template branches use
  `svelte-check` / `vue-tsc` instead.
- Biome lints `.ts`/`.js` across all branches. Vue SFCs (`.vue`) are
  natively supported; Svelte SFCs (`.svelte`) are excluded (false positives
  on reactive `$:` syntax) — `svelte-check` covers those.

## Committing

This repository also hosts the site (`site/`, Astro + Starlight) and the
scaffolder (`create-dulak/`). Update docs alongside code changes — the docs
drift is the number-one contribution smell.

The repository uses branch namespaces for templates (`template/*`). Tag
archived eras with `legacy/*` tags rather than deleting history.
