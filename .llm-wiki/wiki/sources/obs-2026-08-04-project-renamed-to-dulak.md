# ⭐ Observation: Project renamed to Dulak
Project renamed from 'elysia-inertia-boilerplate' to 'Dulak' — the Banjar word for 'bored/bosan', chosen to embody the 'deliberately boring' philosophy. Beats 'bosan' (generic Indonesian word, unsearchable) because it is distinctive, searchable, pronounceable, and carries a local-language origin story. Renamed in package.json (name, repository.url, keywords) and README (title, CI badge, Philosophy section notes the name origin). Remaining manual step for owner: rename GitHub repo to maulanashalihin/dulak + git remote set-url. Old URLs redirect automatically once renamed.
