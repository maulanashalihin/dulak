# Requires a Cloudflare API Token with these permissions:
#   Zone → DNS → Edit
#   Zone → Zone → Read
#   Account → Account Filter Lists → Read (for origin rules)
#
# Create one at: https://dash.cloudflare.com/profile/api-tokens
# Template: "Edit zone DNS" (add Zone → Read if missing)

Set up Cloudflare as the reverse proxy for my Dulak app. Here are
the details:

- Cloudflare API token: CLOUDFLARE_API_TOKEN
- Domain: your-domain.com
- Server IP: SERVER_IP
- App port: 4000

Steps:
1. Use the Cloudflare API (https://api.cloudflare.com/client/v4)
   with the token above.
2. Find the zone ID for the domain.
3. Create an A record for the domain pointing to the server IP,
   with proxied: true (orange cloud).
4. Set SSL/TLS mode to Flexible (edge terminates TLS, talks HTTP
   to origin on port 4000).
5. Create an Origin Rule: rewrite Host header to the domain for
   incoming requests matching the hostname. This ensures CSRF
   and OAuth work correctly.
6. On the server, set up UFW to only allow Cloudflare IPs on port 4000:
   - Allow OpenSSH
   - Fetch Cloudflare IP ranges from the API and allow them on port 4000
   - Enable UFW
7. Verify: curl https://your-domain.com/health should return 200.
8. Tell me the status and any issues.
