Deploy my Dulak app on my VPS using Docker. Here are the details:

- SSH: ssh USER@SERVER_IP
- GitHub repo: https://github.com/YOUR_USER/YOUR_REPO.git
- Domain: your-domain.com (or "none" if no domain yet)
- Install path: /opt/dulak
- App port: APP_PORT

Steps:
1. SSH into the server.
2. Install Docker and Docker Compose if not already installed.
3. Check if the app port is already in use (ss -tlnp | grep APP_PORT).
   If it is, pick the next available port and use that instead.
4. Clone the repo to the install path.
5. Copy .env.example to .env and change these three lines:
   - PORT=<the port you chose>
   - NODE_ENV=production
   - APP_URL=https://your-domain.com (or http://SERVER_IP:<port> if no domain)
   Leave the rest as-is (DATABASE_PATH is relative, works anywhere). The docker-compose.yml reads PORT from .env automatically — no need to edit the compose file.
6. Run `docker compose up -d --build`.
7. Wait for the container to be healthy (check with `docker compose ps`).
8. If the port is not in UFW rules, allow it: sudo ufw allow <port>/tcp.
9. Verify: curl http://localhost:<port>/health should return 200.
   Also confirm the app runs as non-root: docker compose exec app id
   should output uid=1000(bun), NOT uid=0(root).
10. Save these three lines to a file called `deploy.env` in my local
    project root (NOT on the server) and add it to .gitignore.
    Use the actual values from above (not the placeholders):
    ```
    DEPLOY_SSH=<the USER@SERVER_IP from above>
    DEPLOY_PATH=<the install path from above>
    DEPLOY_PORT=<the port you chose in step 3>
    ```
11. Tell me the status, the port used, and any issues.
